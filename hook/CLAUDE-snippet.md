## Spoken summary (claude-code-voice)

End EVERY response with a final line starting with the marker `🔊 ` followed by a
one-sentence spoken summary (about 15 words, plain conversational words — no code,
file paths, or markdown). A Stop hook reads that line aloud, so write it to be
heard, not read.
